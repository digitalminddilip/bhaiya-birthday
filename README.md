# Project BHAIYA — Birthday Website

A responsive, bilingual (English + Hindi) birthday surprise website for Harishchandra Sharma, created by Dilip.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

## Deploy to Vercel
1. Sign in to Vercel and choose **Add New → Project**.
2. Import a GitHub repository containing these files, or use Vercel's supported deployment flow.
3. Framework preset: **Other**. Build command: leave blank. Output directory: `.`
4. Deploy. Share the generated public URL with your brother.

## Customize
- Edit names and messages in `index.html`.
- Replace images in `assets/` and update the matching image paths in the gallery.
- The project uses no backend and does not collect visitor data.
- Fonts are loaded from Google Fonts; if offline, fallback fonts are used.

Note: The site uses CSS-based cake/visual effects and canvas confetti; it does not require a paid API.
